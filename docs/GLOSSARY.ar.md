# مسرد المصطلحات — Wex (العربية الفصحى)

مصطلح واحد لكل مفهوم في واجهة المتجر ولوحة الإدارة والبريد والإشعارات والأسئلة الشائعة.
يفحصه آلياً `wex-web/scripts/check-copy.mjs` (ضمن `npm run check:all`). المرادفات في العمود الأخير ممنوعة.

| المفهوم | المصطلح المعتمد | ممنوع |
|---|---|---|
| order | الطلب / طلبك / الطلبات | الأوردر، الطلبية |
| transfer receipt | إشعار التحويل | الإيصال، إيصال التحويل، وصل التحويل |
| price lock | تثبيت السعر / السعر مثبّت | قفل السعر، تجميد السعر |
| delivery | التوصيل | الشحن، رسوم الشحن، منطقة الشحن |
| pickup | الاستلام من المحل | الاستلام من الفرع |
| cart | السلة | عربة التسوق، الكارت |
| currency label | ج.س (مع مسافة غير منقسمة قبلها) | جنيه، SDG في الواجهة |
| customer inspection | يتأكد المشتري من الجهاز عند الاستلام | أي ادعاء فحص أو ضمان أو أصالة من المتجر |
| bank transfer | التحويل البنكي | الدفع الإلكتروني (لا توجد بوابة دفع) |
| sign in | تسجيل الدخول | اللوج إن |
| verification code | رمز التحقق | الكود، OTP في الواجهة |

## قواعد الصياغة
- الفصحى فقط؛ لا عامية (مثل: شنو، عاوز، كدا، هسي، دا/دي).
- علامات الترقيم العربية داخل النص العربي: ، ؟ ؛ (لا , ? ;).
- لا مسافتان متتاليتان؛ لا نقطتان في نهاية العناوين.
- الأزرار تبدأ بفعل: «أضف إلى السلة»، «أكّد الطلب»، «ارفع إشعار التحويل».
- رسائل الخطأ: ماذا حدث + ماذا يفعل العميل.
- لا تظهر للعميل: الدرهم الإماراتي (AED)، سعر الصرف، أسماء المشرفين.
- لا ادعاءات بلا سند: ضمان، فحص، اختبار، أصلي، «الأكثر طلباً/مبيعاً»، وكيل/رسمي/معتمد، مؤقتات استعجال وهمية.
